# Store screenshots

Five 1280×800 PNGs per language (`en/`, `vi/`), generated by `npm run screenshots`.

| File               | Shows                                                                   |
| ------------------ | ----------------------------------------------------------------------- |
| `01-reading-toc`   | A document with the automatic table of contents and reading-time        |
| `02-search`        | Keyword search with page results                                        |
| `03-summary`       | AI summary of one section: summary, key points with pages, terms        |
| `04-focus-mode`    | Focus mode: dimmed page with a bright reading band                      |
| `05-ocr`           | OCR on a scanned page: the OCR panel, the "OCR" badge, the updated TOC  |

## How they are made

- The script loads the built extension (`dist/`) into Chromium with Playwright and uses the real viewer.
  It is run by hand and is not part of `npm test` or CI.
- The demo document is original text written for this purpose; Chromium prints it to a PDF with a real text layer at run time.
  Nothing is copyrighted. The OCR shot uses `tests/fixtures/scanned-vi.pdf` (self-generated) in both languages.
- **The AI summary in `03-summary` is sample output, not a real model's answer.** The script answers the request to
  `http://localhost:11434` with a fixed JSON reply. Use captions or listing text that call it an illustration.
  The model label shown in the panel (`llama3.2`) is therefore a placeholder.

## Regenerate

```bash
npx playwright install chromium   # once, ~120 MB
npm run fixtures:scan             # if tests/fixtures/scanned-vi.pdf is missing
npm run build
npm run screenshots               # add -- --lang=en or -- --skip-ocr to narrow it
```
